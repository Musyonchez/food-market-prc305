# Mapishi Market (working name) - PRC 305 Web Development Project

A food marketplace where each cook has a profile, a menu and prices ("Know who's cooking").
Built with WordPress + WooCommerce + Dokan, hosted on InfinityFree. Daystar University, Sept-Dec 2026.
